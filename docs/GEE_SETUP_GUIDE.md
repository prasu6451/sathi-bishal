# Google Earth Engine (GEE) Setup & Integration Guide

Step-by-step instructions for installing, authenticating, and linking Google Earth Engine (GEE) with the **SATHI / SIH26001** system.

---

## Step 1: Install `earthengine-api` Python Package

Open terminal or command prompt and run:
```bash
pip install earthengine-api google-auth
```

---

## Step 2: Register a Free Google Cloud / Earth Engine Project

1. Open your browser and go to [Google Earth Engine Signup](https://signup.earthengine.google.com/) or [Google Cloud Console](https://console.cloud.google.com/).
2. Sign in with your Google Account.
3. Click **Create Project** (or select an existing project).
4. Enter a Project Name (e.g., `sathi-landslide-system`).
5. Copy your **Google Cloud Project ID** (e.g., `sathi-landslide-system-45123`).

---

## Step 3: Run Interactive Authentication

In terminal, execute:
```bash
earthengine authenticate
```
- A browser tab will open automatically.
- Log in with your Google account and grant permissions to Google Earth Engine.
- Copy the authorization token generated by Google.
- Paste the authorization token into your terminal prompt and press `Enter`.

---

## Step 4: Configure Project Credentials in SATHI

Add your Project ID to `backend/.env`:
```env
EARTHENGINE_PROJECT=sathi-landslide-system-45123
ALPHAEARTH_PROVIDER=real
```

Or set environment variables in PowerShell:
```powershell
$env:EARTHENGINE_PROJECT="sathi-landslide-system-45123"
$env:ALPHAEARTH_PROVIDER="real"
```

---

## Step 5: Test GEE Connection in Python

Run this short python script to verify authentication:
```python
import ee
ee.Initialize(project="sathi-landslide-system-45123")
print("✅ Google Earth Engine Successfully Connected & Verified!")
```

When connected, `AlphaEarthExporter` in [`ai/data_collection/alphaearth/export_alphaearth.py`](file:///c:/Users/PK/Desktop/sathi/ai/data_collection/alphaearth/export_alphaearth.py) extracts live Sentinel-2 / Landsat satellite imagery and sets `alphaearth_status = VERIFIED`.
