# Experiments & Evaluation Artifacts

This directory stores evaluation metrics, confusion matrices, and feature importance analyses generated during model validation and training runs.
- `results/metrics.json`: JSON output containing Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC.
- `results/feature_importance.csv`: Rank-ordered feature importance listing.
- `results/feature_importance.png`: Feature importance visualization plot.
